# OpenAPI

В каталоге хранятся зафиксированные OpenAPI 3.1-спецификации:

- `kitchen-api.json` — пользовательский и партнёрский API платформы;
- `restaurant-api.json` — API демонстрационного заведения.

Схемы экспортируются непосредственно из FastAPI-приложений без запуска PostgreSQL
или Docker:

```bash
make openapi
```

Тест `tests/test_openapi.py` сравнивает сохранённые файлы со схемами, полученными
из текущего кода. Если HTTP-контракт изменён намеренно, необходимо повторно выполнить
команду экспорта и включить обновлённую спецификацию в тот же коммит.

Во время разработки актуальные схемы также доступны по маршруту `/openapi.json`
каждого запущенного сервиса.
